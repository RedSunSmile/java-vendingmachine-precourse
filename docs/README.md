# 자판기

## 기능 목록

- [x] 보유 금액 입력 받기
- [x] 보유 금액 검증 (숫자, 10원 단위)
- [x] 보유 금액으로 동전 무작위 생성
- [x] 자판기 보유 동전목록 출력
  - ex) 500원 - 0개 / 100원 - 4개
- [x] 상품 입력 파싱
  - ex) `[콜라,1500,20];[사이다,1000,10]`
- [x] 상품 가격 검증 (100원 ↑, 10원 단위)
- [x] 투입 금액 입력
- [x] 투입 금액 검증 (숫자)
- [x] 남은 투입 금액 출력
  - ex) 투입 금액: 3000원
- [x] 구매할 상품명 입력
  - ex) 구매할 상품명을 입력해 주세요. → 콜라
- [x] 상품 구매 (금액 차감, 재고 감소)
- [x] 구매 종료 판단 (잔액 < 최저가 or 품절)
- [x] 최소 개수 동전으로 잔돈 계산
- [x] 잔돈 부족 시 가능한 만큼만 반환
- [x] 잔돈 반환된 동전 출력
- [x] 사용자 예외 처리
  - `IllegalArgumentException` 발생
  - "[ERROR]"로 시작하는 에러 메시지를 출력 후 해당 부분부터 다시 입력 받기
